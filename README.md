# AquaSense: early disease warning for salmon farms

**Detect fish disease 48 hours before it's visible.**

🌐 **Live app: [fish-guardian-ai.lovable.app](https://fish-guardian-ai.lovable.app)**. Open **/demo** to explore a sample farm without signing up.

AquaSense is a web app that warns salmon farmers when a cage is at risk of a disease outbreak. It combines live ocean data with per-cage sensor readings, scores each cage's risk, raises a spoken alert when a cage turns critical, and lets the farmer ask an AI assistant what to do.

## The problem

Norwegian salmon farming loses more than **€940 million** a year to fish deaths. According to the Norwegian Veterinary Institute's *Fiskehelserapporten*, most of these losses come from disease, sea-lice treatments and environmental stress. That stress builds up unseen for days before the fish show symptoms.

The idea behind AquaSense is to treat this as a data problem. Water temperature, waves and wind drive the oxygen level in a cage, and low dissolved oxygen, below 7 mg/L, is one of the clearest early warning signs of an outbreak. Watching that signal can flag trouble about 48 hours early.

## What the app does

| Page | What you can do |
|---|---|
| **Home** (`/`) | Read what AquaSense is and how it works |
| **Onboarding** (`/onboarding`) | Register your farm: name, licence number, species, location, number of cages and fish per cage |
| **Dashboard** (`/dashboard`) | See every cage's risk score from 0 to 10, its oxygen, temperature, pH and mortality, a 7-day trend line, the value at risk in euros, and nearby farms with reported disease |
| **Spoken alert** | When a cage is critical, the dashboard reads the alert aloud and repeats it every 25 seconds |
| **AI assistant** (`/ai-assistant`) | Ask questions about your farm in plain language. The assistant sees your live cage data |
| **Demo** (`/demo`) | A ready-made farm in Hardangerfjord with 6 cages. No account needed |
| **About** (`/about`) | Background on the problem and the data sources |

## How it works

```
 Open-Meteo Marine API ──► sea temperature, waves, wind for the farm's location
                                      │
                                      ▼
                    risk model (src/lib/marine.ts)
          oxygen estimated from water temperature, combined with
          per-cage readings: oxygen, pH, mortality, wave stress
                                      │
                                      ▼
   Dashboard ──► risk score per cage ──► critical? ──► spoken alert (ElevenLabs)
       │
       └──► AI assistant (Gemini) answers questions using the same cage data
```

**Which data is real and which is simulated:**
- **Real and live:** sea-surface temperature, wave height, air temperature and wind, from Open-Meteo, for the farm's exact coordinates.
- **Simulated:** the per-cage sensor readings. Real farms would have sensors in each cage; here they are generated, calibrated to the cage-failure patterns the Norwegian Veterinary Institute reports.
- **Snapshot:** nearby farms' disease status, based on BarentsWatch Fish Health data for 2024 and 2025. The live BarentsWatch service requires special credentials.

## Project map

Most files in this repository were generated by Lovable as standard building blocks. The ones that make AquaSense what it is are these:

```
src/
├── routes/                  ★ the pages; each file is one page of the website
│   ├── index.tsx              home page
│   ├── onboarding.tsx         register a farm
│   ├── dashboard.tsx          ★ main dashboard: cages, risk, alerts, nearby farms
│   ├── ai-assistant.tsx       chat with the AI assistant
│   ├── demo.tsx               sign into the demo farm
│   ├── auth.tsx               log in / sign up
│   ├── about.tsx              background and data sources
│   └── api/elevenlabs/tts.ts  turns alert text into speech
│
├── lib/                     ★ the logic behind the pages
│   ├── marine.ts              ★ fetches ocean data and computes each cage's risk
│   ├── farm.functions.ts      loads a farm, its cages and the value at risk
│   ├── chat.functions.ts      sends the question and cage data to the AI
│   ├── barentswatch.ts        nearby farms' fish-health status
│   ├── demo.functions.ts      creates the shared demo account
│   └── auth-context.tsx       keeps track of who is logged in
│
├── components/
│   ├── Nav.tsx                top navigation bar
│   ├── AlertSound.tsx         plays the spoken alert
│   ├── Sparkline.tsx          small trend lines on each cage
│   └── ui/                    standard buttons, menus, dialogs (generated, not custom)
│
└── integrations/supabase/   connection to the database (generated)

supabase/migrations/         database tables: profiles, farms, cages, with access rules
promo-video/                 the promo video: 12 scenes with voiceover and music
.lovable/plan.md             the original build plan
```

Files at the top level, such as `package.json`, `vite.config.ts`, `wrangler.jsonc` and the lint and format configs, are settings for building and hosting the website.

## Promo video

The `promo-video/` folder contains a short video presenting AquaSense in 12 scenes: hook, problem, cost, solution, sensors, dashboard, 48-hour alert, simulator, market, roadmap, and credits. It is written as code with Remotion. The voiceover is generated with ElevenLabs by `promo-video/scripts/gen-audio.mjs`, and `promo-video/scripts/render.mjs` renders the final video.

## Run it yourself

```bash
bun install
bun run dev
```

This needs a Supabase project, with its URL and keys in `.env`. The AI assistant needs a Lovable AI key, and the voice alerts need an ElevenLabs API key. Both are set as server secrets and are not stored in this repository.
